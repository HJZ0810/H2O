# 智联迷城手柄 · Arduino 工程 v1.1.0

**Arduino IDE 打开入口：`ExamHandheld/ExamHandheld.ino`。** 这是标准的多文件 Sketch；同目录的 `.cpp/.h` 会一起编译，不能只复制 `.ino`。

适配 R3.1 底板、ESP32-S3 N16R8 开发板、1.8 英寸 ST7735S 横屏（160×128），默认对接 `124.70.71.221:1883`。此版包含用户要求的自动答题演示数据。

## 在 Arduino IDE 使用

1. 安装 Arduino IDE 2，在开发板管理器安装 **esp32 by Espressif Systems 3.3.12**。
2. 解压整个包。在本目录打开 PowerShell，运行 `powershell -ExecutionPolicy Bypass -File .\tools\InstallLibraries.ps1`，将随包八个锁定库复制到 Arduino 草图目录。它会保留内容相同的现有库，遇到不同内容先报出冲突，不覆盖。
3. 如果 Arduino IDE「文件→首选项」的草图位置不同，安装时明确指定：`.\tools\InstallLibraries.ps1 -SketchbookPath '你的草图位置'`。库安装后重启 IDE。
4. 用 IDE 打开 `ExamHandheld/ExamHandheld.ino`，选择 **ESP32S3 Dev Module**，并按下表设置。
5. USB 烧录/供电前取下底板 JP2，选实际串口，点击验证、上传。此交付没有连接或烧录实板。

| 设置 | 值 |
|---|---|
| Flash Size | 16MB (128Mb) |
| Flash Mode | QIO |
| PSRAM | OPI PSRAM |
| Partition Scheme | 16M Flash (3MB APP/9.9MB FATFS) |
| USB CDC On Boot | Enabled |
| USB Mode | Hardware CDC and JTAG |
| Arduino Runs On / Events Run On | Core 1 |

也可运行 `.\tools\build.ps1` 用已安装的 Arduino CLI 编译。库已附在 `libraries/`，这个构建脚本直接使用随包库。完整 FQBN 见 `validation/fqbn.txt`。

## 配网和账号

首次启动显示临时热点名称、密码、Wi-Fi STA MAC；串口监视器设 115200 也能查看。教师先用**数字组号与该 MAC**在现有教师端注册，得到的同一密码既用于本组 MQTT，也用于学生网页登录。HTTP `/api/data` 登录返回的 token 是另一种凭据，不要填入 MQTT 密码栏。

手机连屏幕所示热点，浏览器打开 `http://192.168.4.1`，填写 2.4GHz Wi-Fi、组号和密码。默认主机 `124.70.71.221`、端口 `1883`；选择屏幕方向和初始化标签，保存后自动重启。两路 MQ 默认关闭，接好后再启用。密码保存在设备 NVS，不写入源码，设置页不回显旧密码。

按住 F1 再上电/复位可强制配网；主菜单也可打开设置。USB 日志使用 ESP32-S3 原生 USB CDC 口。

## 按键和自动演示

| 场景 | 操作 |
|---|---|
| 主菜单 | 上下选择，OK进入；**短按左上角 F1 启动自动演示** |
| 手动作答 | F1/F2/F3/F4 选择 A/B/C/D；多选再按可取消；OK提交 |
| 已在剧情、题目或解析中 | **长按 F1 启动演示**，短按 F1 仍保留 A 选项功能 |
| 演示运行中 | **任意键按下即停止**，停下后可以继续手动操作 |
| 剧情、解析 | 上下滚动、左右翻页；OK先翻页，末页后继续 |
| 题目 | 长按 OK 请求锦囊；长按 F4 查看传感器，OK返回 |
| 暂停页 | 自动恢复连接和进度；OK再次请求同步 |
| 暂停/通关页 | F1设备信息，F4传感器 |
| 设备信息 | 长按 F2 打开配网确认 |

长按约 800ms，去抖约 30ms。启动演示的那次按键不会马上把演示关掉；停止演示的同次松开也不会误选答案。

演示按正常 `start → story_next → answer → continue` 流程逐步取题、选择和提交。阅读每页约 **3.2秒**，选择每个选项约 **1.2秒**，选好后再次逐页展示，再提交；题目较长时会自动翻页。使用 2026-11-11 服务器题库的题号、答案和题目指纹；题干、题型或选项有变化就停止，避免错答。没有直接设置分数的接口。

**从尚未开始的新组运行完整演示可获得35题、350分。** 已有进度时继续原进度，保留原来已经发生的失分；已通关组不会被重置或重复加分。如需重新从零演示，应由教师安排独立测试组。

## 修复后的答题与恢复

服务器协议2为每次变更带上随机启动前缀、请求序号、考试会话和进度版本。题号必须吻合；相同请求只生效一次，旧请求不能推进新题；每个题号最多计10分，全场最高350分。重试仍可补回之前未得分的题。

判题先保存解析和成绩，读完解析后由设备确认继续。断线、超时或重启后，设备只请求服务器权威快照，恢复原剧情、题目、锦囊、解析或最终证书，不盲目重发答案。新固件不再依赖 HTTP 成绩查询才能继续考试。服务器进度持久化到 `game_state.json`。

## 传感器和接线

| 功能 | GPIO |
|---|---|
| TFT CS/DC/RST/MOSI/SCK | 15 / 2 / 21 / 13 / 14 |
| DHT11 | 5 |
| MQ1 AO / MQ2 AO / 光敏 | 1 / 4 / 6 |
| F1 / F2 / F3 / F4 | 7 / 8 / 9 / 10 |
| 上 / 下 / 左 / 右 / OK | 11 / 12 / 16 / 17 / 18 |

外部电源模块固定 **5V**。MQ AO 经过底板 22kΩ/33kΩ 分压，固件按0.6还原 AO 电压，DO未接主控。DHT按底板3.3V逻辑使用。光敏仅显示ADC、毫伏和相对百分比，未经标定不输出lux；MQ未经标定不输出ppm。

传感器在线每约5秒上报。DHT无效发送null；网页原位置将缺失值显示为「—」，相对光照显示百分比。网页布局、按钮及面板保持原样，没有新增MQ面板。

## 文件与验证

- `ExamHandheld/`：完整 Arduino 源码，包括可见过程的测试演示。
- `libraries/`：八个随包依赖和版本/内容锁。`python -B .\tools\verify_libraries.py`可离线校验。
- `binaries/`：本版完整构建生成的应用、引导程序和分区表；单独的应用bin不可当完整镜像写到地址0。
- `tools/flash.ps1 -Port COM7`：按Arduino配方烧录，COM7须换成实际端口。
- `validation/`：实际测试日志、构建日志、线上验证与清理结果、后台浏览器截图。
- `tools/test.ps1`：可在已安装C++17编译器和Python的电脑回放本地固件测试，不向生产服务器发送答题数据。

本包不含生产账号密码、私有服务器源码或整套题干。`DemoAnswers.h` 是用户授权的演示用答案映射。

尚未进行实板烧录与屏幕、按键、传感器电气验证；软件回归和完整编译不能替代实物测试。详细验证结果见 `validation/验证报告.md`。
