# R9 手柄固件 2.0.1-r9-ui

在 v1.4 业务层之上重做显示与板级适配。同一份源码支持自研 R9.1.3 双板与「ESP32S3 功能板 TFT版」验证板，差异只在 `Board.h` 的一份分支。

## 相对 1.4.0-r9-outline 的变更

| 项目 | 1.4.0-r9-outline | 2.0.0-r9-ui |
| --- | --- | --- |
| 显示驱动 | Adafruit_ST7735 + GFXcanvas16 | 自写 Panel，引脚、控制器、分辨率运行时给出 |
| 界面结构 | 纯文本按行输出 | 状态栏 / 卡片 / 内联图标 / 底部键位提示 |
| 中文排版 | 12 px 全字库直接绘制 | 12/16 px 双档 + 伪粗体，折行按像素宽度计算 |
| 菜单 | 5 项固定排布 | 按可用高度自动决定可见行数并跟随选中项滚动 |
| 题目页 | 选项固定高度 | 选项高度按实际行数计算，超长文本进入滚动视口 |
| 板级适配 | 固定 R9.1.3 引脚 | `BOARD_VERIFY` 宏切换到验证板引脚与外设 |
| 可选外设 | 全部必填 | `-1` 表示该路不存在，传感器与执行器自动跳过 |

## 板型对照

| 信号 | R9.1.3 自研板 | 验证板 |
| --- | --- | --- |
| TFT SCL | IO14 | **IO38** |
| TFT SDA | IO13 | **IO21** |
| TFT CS | IO15 | **IO10** |
| TFT DC | IO2 | **IO11** |
| TFT RES | IO21 | **IO12** |
| TFT BLK | 常亮 | **IO9** |
| DHT11 | IO5 | **IO8** |
| MQ-2 / MQ-135 | IO1 / IO4 | 不存在，IO1 为光敏 |
| 按键 | IO7/8/11/12/16/17/18 | **IO0/14/15/16/17/18/13** |
| 电机 A/B、舵机 | IO41/40/39、IO48/38/43、IO42 | 无功率级，映射到 IO4/5/6 板载 LED |

验证板的 TFT 引脚来自原理图 U2，已于 2026-11-21 实测确认：`3 SCL=IO38, 4 SDA=IO21, 5 RES=IO12, 6 DC=IO11, 7 CS=IO10, 8 BLK=IO9`。

**接线注意**：ESP32 的 `SPI.begin()` 重复调用不会切换引脚映射。切换引脚必须先 `end()`，或每次上电只配置一次。早期扫描固件因连续 `begin()` 造成「多组接法都能出图」的假象，实际始终使用第一次配置的引脚，详见 [调试记录](../validation/r9-ui-v2-debug.md)。

## 编译与烧录

```bash
arduino-cli compile \
  --fqbn "esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi,PartitionScheme=app3M_fat9M_16MB" \
  --libraries ../libraries \
  --build-property "compiler.cpp.extra_flags=-DBOARD_VERIFY" \
  ExamHandheldV2
```

去掉 `-DBOARD_VERIFY` 即编译自研板版本。应用占用 1,600,438 字节（3 MB 分区的 50%），静态变量 51,484 字节（15%）。默认 1.25 MB 分区不足以容纳 12 px 与 16 px 两套 GB2312 点阵，必须使用 3 MB 应用分区。

## 界面结构

`Canvas` 是 16 位 RGB565 画布，`Gfx` 提供抗锯齿圆角、渐变、线段与图标，`Theme` 按短边给出三档度量（≤140 / <200 / ≥240），`UiRender` 只依赖 `TextPainter` 抽象。设备端由 `FontCN` 把 U8g2 点阵写进画布，主机端可换成 GDI 或 FreeType 渲染同一套绘制代码。

`Panel` 支持 ST7735、ST7789、ILI9341 三种初始化表，MADCTL 按 0/1/2/3 四档旋转，显存偏移可单独指定。
