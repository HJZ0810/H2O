## 否决、扣分与截止

- V1 按板判打样。未打样板 E1 为 0，两板均未打样时 H ≤12、总分 ≤70。V2 任一板缺规定身份丝印，E2 记 0 并额外扣 2。V3 抄袭、代做或整段复制按相关项记 0。V4 使用他人 PCB 工程打样，H 记 0。
- D1 现场跑不通且无法定位，相关 A/B 项打折，按②口径不低于 50%。D2 个人讲不清关键实现，每处扣 1、最多 3。D3 擅改抽签配置且未报备，B1 扣 9。D4 短路或间距 DRC 错误仍送打样，E1 扣 2。D5 关键材料每缺一项扣 1.5、最多 4.5。D6 双板理由未入报告 3.2，扣 1。
- ②规定第 2 周最后一天 24:00 截止，以 Gitee 最后提交时间为准。每迟 1 天扣总分 2，迟 3 天以上按 60% 计。截止后补交进 `late/` 并在 README 说明，保留原提交。具体公历日期须结合教学周起始日核定。
- 现场每组 12 分钟，硬件 3、A 2、B 3、随机仓库文件 2、原理追问 2。组级评分与个人系数另算，互评由教师收取。
