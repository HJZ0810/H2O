## 一氧化二氢 R10 · 24014 组装配与实机验收候选

本版面向源地 YD-ESP32-S3 **25.40 mm** 双排开发板。任务 A 通过手柄按键参加课程闯关。任务 B 按本组抽签使用 OneNET、DHT11、MQ-2、MQ-135、直流风扇和 SG90。

| 下载 | 用途 |
|---|---|
| `H2O-R10-firmware.zip` | 综合手柄与独立监测两套自研板固件，含分区参数、分区文件、编译摘要及 SHA-256。 |
| `H2O-R10-hardware.zip` | 嘉立创可编辑工程、两板钻孔核对、SG90 转接 DXF 与 1:1 配钻 PDF。包内宽版 Gerber 保留 R9 基线丝印。 |
| `H2O-R10-site-patch.zip` | 项目官网增量更新包，含发布和回滚说明。 |

### 从 R9 到 R10

| 范围 | 修正与验证 |
|---|---|
| 手柄和执行板 | 修正图上旧排距和板卡标识。两份原始 Gerber 核对 SHA 后独立反量，手柄 44/44 个排母孔符合 25.400 mm 排距、2.54 mm 节距。双端 IDC 的 10 个信号按针号核对。 |
| SG90 安装 | 历史 MG996R 四孔的中心距为 48.50 × 10.00 mm。新附件沿用这四孔固定转接板，SG90 的固定耳按到货件配钻。 |
| 任务 A | 正式构建使用实体按键作答，关闭自动答题和串口按键注入。网页退出、换组或凭据失效时清空旧成绩。现役状态机离线回归 28/28。 |
| 任务 B | 统一两套固件的风扇百分比和舵机角度下发，校验输入，按执行结果回执。MQ 传感器标为未标定相对值。自建 WS 仅转发本设备遥测，网页经授权的服务端接口下发。 |
| 浏览器 | 本地桌面与手机分别设置风扇 55% 和舵机 120°，共收到 4 次模拟确认。旧历史、缺测、零值和设备切换均有专项回归。 |

### 实机验收与制板状态

下单前需用 R10 源工程导出与新丝印一致的生产文件，完成原生检查、SG90 试装、供电与带载验证。默认固件兼容原项目 OneNET 1883 接入，部署镜像或 TLS 前需配置对应凭据及信任锚。正式任务 A 进度以课程服务器记录为准，任务 B 以 OneNET 记录与实物动作验收。课程要求的报告、视频和实物照片见评分矩阵。
