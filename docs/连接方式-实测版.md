## 二、任务 A：密码算法

规范要求密码必须由代码算，不能手填。固件在 `Auth.h`，服务器端用同一个算法校验。

```
1. MAC 去掉分隔符，得到 12 位十六进制，例如 64E8337F4DB4
2. SUM   = 组号(十进制) + 2026
3. 12 位串每 4 位一组转十进制，得 M1 M2 M3
4. TOTAL = SUM + M1 + M2 + M3
5. 密码  = TOTAL mod 2^24，格式化成 8 位小写十六进制（不足补 0）
```

本机实测：组号 `24014`，MAC `64:E8:33:7F:4D:B4` →

```
SUM   = 24014 + 2026 = 242427
M1..M3 = 0x64E8, 0x337F, 0x4DB4 = 25832, 13183, 19892
TOTAL = 242427 + 25832 + 13183 + 19892 = 301334 = 0x00049916
密码   = 00049916
```

串口启动日志会打印这个值，可直接对照：

```
[auth] group=24014 mac=64:E8:33:7F:4D:B4 pass=00049916
```

> 注意：必须在 `WiFi.mode()` 之前也能取到 MAC。`WiFi.macAddress()` 在 Wi-Fi 未初始化时返回
> 全 0，算出来的密码必然是错的；固件用 `esp_read_mac()` 从 eFuse 直读。

## 三、任务 B：OneNET 接入

### 连接三要素

```
clientId = 设备名称      yhyegj-01
username = 产品ID        UAN4hdnSC1
password = 用设备密钥算出的 token（不是密钥本身！）
```

### token 算法（2018-10-31 版）

```
resource           = products/{pid}/devices/{dev}
stringForSignature = et + "\n" + method + "\n" + resource + "\n" + "2018-10-31"
sign               = base64( HMAC-SHA1( base64decode(设备密钥), stringForSignature ) )
password           = version=2018-10-31&res={resource}&et={et}&method=sha1&sign={sign}
```

两个必须注意的点：

1. **`et` 是绝对过期时间**，设备必须先 NTP 对时。时钟停在 1970 时算出的 token 一定过期，
   但服务端只会回 `CONNACK 4`（用户名或密码错误），非常容易被误判成凭据填错。
2. 直接把设备密钥当密码填，同样是 `CONNACK 4`。密钥只是 HMAC 的 key。

### 主题

```
上报      $sys/{pid}/{dev}/thing/property/post
上报回执  $sys/{pid}/{dev}/thing/property/post/reply
云端下发  $sys/{pid}/{dev}/thing/property/set
下发回执  $sys/{pid}/{dev}/thing/property/set_reply
```

### 物模型（6 个功能点）

| 标识符 | 名称 | 类型 | 读写 | 单位 |
|---|---|---|---|---|
| temperature | 温度 | float | 只读 | °C |
| humidity | 湿度 | float | 只读 | %RH |
| smoke | 烟雾浓度 | int32 | 只读 | ppm |
| air | 空气质量 | int32 | 只读 | ppm |
| fan_level | 风扇档位 | int32 | 只读 | % |
| servo | 舵机角度 | int32 | 读写 | ° |

导入模板：`software/tools/thingmodel-h2o.json`。导入会覆盖原有功能点，导完必须点「保存」。

## 四、网页面板怎么连（路线二 / 三）

浏览器不能直接开 TCP 连 1883，要走 **MQTT over WebSocket**：

| 入口 | 地址 | 说明 |
|---|---|---|
| TLS | `wss://mqtts.heclouds.com:8084/mqtt` | 首选 |
| 明文 | `ws://mqtts.heclouds.com:8083/mqtt` | 备选，个别网络更顺 |

认证参数与 TCP 完全一致（clientId / username / token），面板里在浏览器端现算 token。

R10 面板从服务端读取设备数据。设备密钥只配置在设备或可信服务端。见仓库首页的 R10 连接及验收说明。

> 安全提醒：设备密钥写进网页 = 任何人打开都能控制你的设备。仅用于课程演示，
> 别把它部署到公开仓库的 Pages 上还带着真密钥。

## 五、排错速查

| 现象 | 判断 | 处理 |
|---|---|---|
| `CONNACK 4` | 凭据错 **或** token 过期 | 先看设备时间是否 > 17 亿 |
| `state=-2` | 本地网络没通 | 查 WiFi、DNS、端口 |
| `state=4` | 服务端明确拒绝 | 对照上面三要素 |
| 连上了但属性是 `undefined` | 物模型标识符对不上 | 导入对应模板并保存 |
| 网页连不上 | 端口/路径错 | 8084 + `/mqtt` |
